# Play Console data safety answers

Use these when filling **App content → Data safety**. The Android app has no
`INTERNET` permission and does not talk to a backend.

## Overview

| Question | Answer |
| --- | --- |
| Does your app collect or share any of the required user data types? | **No** |
| Is your app encrypted in transit? | Not applicable (no network) |
| Do you provide a way for users to request that their data is deleted? | Not applicable (nothing collected) |

## Data types

Mark **all** data types as not collected and not shared, including:

- Location
- Personal info
- Financial info
- Health & fitness
- Messages
- Photos and videos
- Audio files
- Files and docs (firmware is processed on-device only; not collected by you)
- Calendar, contacts
- App activity
- Web browsing
- App info and performance
- Device or other IDs

USB serial traffic and `.bin` contents never leave the phone.

## Security practices

- Independent security review: No
- Committed to Play Families Policy: No (not a kids app)
- Data collected: None
